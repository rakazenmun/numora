# Numora
A lightweight web app that explores datasets

## Installation

### Compilation
Open your terminal, then:
```bash
g++ numora1.cpp -o numora
```

### Run numora:

Windows (command prompt):
```cmd
./numora 
```
Windows (powershell):
```powershell
./numora.exe
```
macOS / Linux:
```bash
./numora.out
```
